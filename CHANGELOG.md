# Changes in 2.3.0

First version of Seamless Loading Screen Continued, an unofficial continuation of Minenash's mod.

- Ported to Minecraft 26.2 and 26.3 (Fabric only)
- The screenshot is also taken when you close the game window while in a world
- The "Server's Default Display Mode" setting now applies to servers that have no mode stored yet
- Rejoining right after leaving no longer reads a half written screenshot
- Fixed the screenshot folder being nested twice; existing screenshots are moved over automatically
- Removed the screenshot resolution setting, screenshots use the window's resolution
